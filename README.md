## 💾 HOW TO USE THE DATA FILES

### Step 1: Import Sales Data
```
Power BI Desktop
→ Home → Get Data → Text/CSV
→ Browse to sales_data.csv
→ Load
→ Apply transformations (see Power_Query_Scripts.md)
```

### Step 2: Import Finance Data
```
Home → Get Data → Text/CSV
→ Browse to finance_data.csv
→ Load
→ Link to Sales via ProductID
```

### Step 3: Connect to Live Data (Later)
```
When ready for production:
→ Replace CSV files with SQL/Excel source
→ Update Power Query connection strings
→ Test refresh schedule
→ Deploy to Power BI Service
```
